# منصة الشموع المحلية (Trading Platform)

منصة رسم شموع احترافية شبيهة بـ Trading View تعمل بالكامل في متصفحك من ملف واحد — بدون خادم وبدون إنترنت.

## التشغيل
1. نزّل ملف `index.html`.
2. افتحه بنقرة مزدوجة في أي متصفح حديث. انتهى.

## الميزات
- **أزواج غير محدودة**: فوركس / كريبتو / أسهم — ولكل زوج شموعه ورسومه وإعداداته المستقلة.
- **رفع بيانات الشموع**: ملف CSV/نص أو لصق مباشر، مع خيار الدمج أو الاستبدال.
  - تعرّف تلقائي على الترويسة وترتيب الأعمدة وصيغ التاريخ (قياسي، MT4/MT5، Unix timestamp، تاريخ أمريكي/أوروبي، فواصل `,` `;` `Tab`).
- **الريبلاي ⏵**: أعد تشغيل الشموع شمعة بشمعة من أي نقطة تختارها — تشغيل/إيقاف (مسافة)، خطوة للأمام/الخلف (الأسهم)، وسرعات متعددة.
- **الفريمات الزمنية**: شريط فريمات في الأعلى يعيد تجميع شموعك تلقائياً (1m 3m 5m 15m 30m 1h 2h 4h 8h 1D 1W 1M) مع زر «أساسي» للعودة للبيانات الخام. تُعرض فقط الفريمات المساوية أو الأكبر من فريم بياناتك.
- **أدوات الرسم (13 أداة)**: خط أفقي، شعاع أفقي، خط عمودي، خط اتجاه، خط ممتد باتجاهين، شعاع، سهم، قناة موازية (بـ3 نقرات)، مستطيل، فيبوناتشي، رسم حر، مسطرة قياس، نص — مع مقابض تحريك وتعديل.
- **استيراد/تصدير CSV** في أي وقت.
- **حفظ دائم تلقائي** في المتصفح (IndexedDB): البيانات والرسوم والإعدادات تبقى بعد إغلاق المتصفح ولا تُمحى إلا بحذفك لها يدوياً.
- متوسطات متحركة MA20 / MA50 / EMA200، تكبير بعجلة الفأرة، سحب، crosshair مع OHLCV ونسبة التغير.
- تراجع (Ctrl+Z) عن عمليات الرسم، ولوحة ألوان للرسومات، وشريط تلميحات متغير حسب الأداة.

## اختصارات
| المفتاح | الوظيفة |
|---|---|
| Esc | إلغاء الأداة / إغلاق النافذة |
| Delete | حذف الرسم المحدد |
| Ctrl+Z | تراجع عن آخر عملية رسم |
| (في الريبلاي) مسافة | تشغيل / إيقاف |
| (في الريبلاي) → ← | خطوة للأمام / للخلف |
