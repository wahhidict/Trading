# منصة الشموع المحلية (Trading Platform)

منصة رسم شموع شبيهة بـ Trading View تعمل بالكامل في متصفحك من ملف واحد — بدون خادم وبدون إنترنت.

## التشغيل
1. نزّل ملف `index.html`.
2. افتحه بنقرة مزدوجة في أي متصفح حديث. انتهى.

## الميزات
- أزواج غير محدودة (فوركس، كريبتو، أسهم…) ولكل زوج شموعه ورسومه المستقلة.
- رفع بيانات الشموع: ملف CSV/نص أو لصق مباشر — دمج أو استبدال.
  - تتعرف تلقائيًا على الترويسة وترتيب الأعمدة وصيغة التاريخ (قياسي، MT4/MT5، Unix timestamp، تاريخ أمريكي/أوروبي، فواصل `,` `;` `Tab`).
- حفظ دائم تلقائي في المتصفح (IndexedDB): البيانات والرسوم والإعدادات تبقى بعد إغلاق المتصفح ولا تُمحى إلا بحذفك لها يدويًا.
- رسم: شموع / خط / مساحة، تكبير بعجلة الفأرة، سحب، crosshair مع OHLCV، خط آخر سعر، MA20 / MA50 / EMA200.
- أدوات رسم: خط أفقي وخط اتجاه قابلان للتحريك — ويُحفظان لكل زوج.
- تصدير CSV، وزر بيانات تجريبية للتجربة الفورية.

## صيغة البيانات المفضلة
```csv
time,open,high,low,close,volume
2024-01-15 10:00,1.0950,1.0961,1.0942,1.0957,1520
2024-01-15 10:15,1.0957,1.0970,1.0955,1.0966,1780
```
